# Query Robustness Variants

This folder contains semantically aligned query variants used for robustness evaluation.

## Variant Types

### Original
The original benchmark research questions used in the paper.

### Paraphrased
Queries rewritten using different wording while preserving the original semantic meaning.

### Keyword-Perturbed
Queries modified through keyword replacement, expansion, or reformulation to test retrieval sensitivity.

## Purpose

These variants were used to evaluate:
- Response Relevancy
- Faithfulness
- Context Relevance
- Response Groundedness

under different query formulations.

GPT5.5 Pro is used to generate those variants.

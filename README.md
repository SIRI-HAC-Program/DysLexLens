# DysLexLens

**DysLexLens** is a low-resource LLM framework for analysing how dyslexic learners discuss learning challenges, coping strategies, support needs, and AI tools in online forums.

This repository provides the supporting materials for the DysLexLens paper, including benchmark questions, evaluation files, example Knowledge Graph outputs, data resources, and human assessment materials. The live application is provided separately so reviewers and users can interact with the tool without installing or running the code locally.

## Overview

DysLexLens examines how dyslexic learners describe their learning challenges, coping strategies, support needs, and solutions, and how they position AI tools within broader educational and social support contexts over time.

The framework supports a complete analysis workflow, from targeted online data collection to query-based reasoning, evidence tracing, and response evaluation. Although this study focuses on dyslexia-related Reddit discussions, the same framework can be adapted to other online forum or social media datasets.

To build a topic-focused corpus, DysLexLens applies a concept dictionary-based filtering method. It then constructs a reusable Knowledge Graph (KG) from the filtered corpus. Given a user query, DysLexLens retrieves relevant semantic triples from the KG and supporting text passages from the corpus.

DysLexLens combines graph-based semantic interpretation with source-grounded response generation. It also allows users to ask follow-up questions and fact-check responses through a three-stage evidence-tracing pipeline.

The repository includes quantitative and qualitative evaluation materials, including RAGAS-based assessment, query robustness analysis, and rubric-based human-grounded response quality assessment.

---

## Main Features

- Concept dictionary-based filtering for building a topic-focused corpus
- Reusable Knowledge Graph construction from online forum data
- Query-based reasoning over semantic triples and retrieved source text
- Source-grounded response generation with cited evidence
- Follow-up question support for deeper analysis
- Evidence tracing for fact-checking and provenance inspection
- RAGAS-based quantitative evaluation
- Query robustness analysis across original, paraphrased, and keyword-perturbed questions
- Rubric-based human assessment for response quality and evidence grounding

This folder contains the benchmark questions used in the paper and evaluation pipeline.

This folder contains data resources used to support the DysLexLens case study.

It includes:

- a sample input file showing the required data format

### `reddit_data/`

This folder is used for Reddit-related data files, where sharing is appropriate.

If the full Reddit dataset cannot be shared due to ethics, privacy, or platform restrictions, this folder should contain only sample, processed, or anonymised files. The `data/README.md` file should explain the required data format and any reuse limits.

### `evaluation/`

This folder contains the evaluation materials used to assess DysLexLens.

It includes three main evaluation components:

1. Quantitative RAGAS assessment
2. Quantitative query robustness assessment
3. Qualitative human-grounded response quality assessment

## Evaluation Components

### Quantitative RAGAS Assessment

The RAGAS evaluation files are available in:

```text
evaluation/quantitative_ragas_assessment/
```

This folder includes:

- `ragas_results_main_and_followups.csv`
- `ragas_summary.md`

The RAGAS assessment reports four metrics:

- Response Relevancy
- Faithfulness
- Context Relevance
- Response Groundedness

These metrics assess whether DysLexLens generates responses that are relevant, factually consistent with the retrieved context, supported by relevant evidence, and grounded in source material.

### Quantitative Query Robustness Assessment

The query robustness files are available in:

```text
evaluation/quantitative_query_robustness_assessment/
```

This folder includes:

- `query_robustness_all30_variants.csv`
- `query_robustness_scores.csv`
- `query_robustness_summary.md`

This evaluation tests whether DysLexLens remains stable when the same questions are expressed in different ways.

The three query variants are:

- original questions
- paraphrased questions
- keyword-perturbed questions

### Qualitative Human-Grounded Response Quality Assessment

The human assessment files are available in:

```text
evaluation/qualitative_human_grounded_response_quality_assessment/
```

This folder includes:

- `human_evaluation_protocol.md`
- `human_audit_completed.csv`
- `audit_summary.md`

This assessment checks whether generated claims are:

- present in the original source
- supported by cited evidence
- interpretable through traceable provenance

## Using the Live Tool

The live DysLexLens tool is intended for reviewers and users who want to inspect the framework without installing software locally.

To use the live tool:

1. Open the live application link.
2. Upload the supported Reddit source CSV.
3. Upload the benchmark question CSV if required.
4. Select the available model and retrieval settings.
5. Run the question-answering workflow.
6. Inspect generated answers, source evidence, Knowledge Graph outputs, and evaluation results.

More guidance is available in:

```text
docs/running_the_tool.md
```

---

## Required Input Format

The Reddit source CSV should include at least the following columns:

| Column | Description |
|---|---|
| `reddit_id` | Unique identifier for the Reddit post or comment |
| `text_cleaned` | Cleaned text used for retrieval and analysis |

The question CSV should include:

| Column | Description |
|---|---|
| `question_id` | Research question identifier, such as `RQ1` |
| `research_question` | Main research question |
| `followup_1` to `followup_5` | Follow-up questions for each main question |

## Project Summary

DysLexLens is designed as an evidence-traceable research assistant for analysing online forum data. It helps researchers retrieve relevant records, generate structured first-pass interpretations, ask follow-up questions, and trace claims back to supporting evidence.

The framework should not be treated as a fully automated interpretation tool. Human review remains important, especially for broad claims, temporal analysis, and educational or institutional interpretations.
